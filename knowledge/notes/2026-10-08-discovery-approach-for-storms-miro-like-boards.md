**Discovery topic: how to specify storms before building them**

- Storms are Miro-like boards. Before building them we need a large set of requirements: the elements, the general behaviour, how Miro-style tools work.
- Much of this is in my head; Claude may not know it at all.
- **Questions:**
  - What input helps most: screenshots, videos, short requirements, feature by feature?
  - How do we start without overcomplicating it and without missing details?
- **Bar:** doesn't need to be 100% accurate, but the first attempt should be solid enough to start building without a chaotic number of bugs.
- **Outcome:** also a general template for exploring a new kind of input/feature, reusable in future.
