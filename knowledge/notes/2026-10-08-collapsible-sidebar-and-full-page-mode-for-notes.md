**Need:** give users more space to do the task they want to do. The sidebar takes a lot of room on small laptop screens.

- **Full-page mode:** notes, and later storms, can go into full-page mode. Possibly a full-page icon somewhere inside the note.
- **Sidebar states:** sometimes it's fine minimized; sometimes it should be hidden completely.
- **Open question:** how this works with the existing file tree in the sidebar.
