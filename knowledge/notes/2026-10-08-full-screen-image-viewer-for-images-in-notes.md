**Feature idea: view images in a note full screen**

- **Use case:** I've added an image to a note. Clicking it should show it full size, full screen, so I can see all of it.
- **Several images:** if the note has more than one image, show left and right arrows to move between them. No thumbnails.
- **Sizing:** we'll need rules for images that are bigger or smaller than the screen, so they don't look odd.
- **How it opens:** right now, clicking an image selects it. I don't want to use double-click. A single click should open the viewer.
- "Lightbox" only describes the kind of behaviour I mean. It doesn't mean a particular library.
